# 安装与使用

1. 将交付的 `vivo-todo-glow-1.0.0.apk` 传到 vivo Y36m，使用文件管理器打开。若系统询问安装来源，允许当前文件管理器安装此 APK。
2. 打开“光点待办”，添加任务。
3. 点“悬浮窗权限”，在系统页面允许光点待办显示在其他应用上层；返回应用。
4. 点“桌面自动收起”，找到光点待办，允许使用情况访问；返回应用。
5. 点“开启悬浮待办”，允许通知。通知用于暂停、恢复、关闭悬浮窗，不是到期提醒。
6. 返回手机桌面，面板会自动展开；切换到其他应用，约1秒后收起。点击悬浮球可临时展开，下一次切换应用会再次收起。

## 日常操作

- 左滑任务露出“完成”，再点按钮：任务立即隐藏并化成光粒子，**5秒内**点“撤销”恢复。动画约0.8秒，包含在5秒窗口内。
- 多项连续完成时，每项都有自己的倒计时和撤销按钮；面板撤销区域可上下滚动。悬浮球出现 `↶` 表示有任务仍可撤销，点击展开操作。
- 点击任务进入编辑，可保存文本、上移、下移或删除。删除也只有5秒撤销窗口。
- 桌面最多显示排序前10项；所有任务在应用中管理。标准字号可同时显示10项，大字号或屏幕空间不足时滚动查看。
- 按住面板顶部“待办”区域拖动；悬浮球也可拖动。任务行的左滑只用于展示完成按钮。
- 点击“收起”可手动收起；返回桌面或切换应用后恢复自动判断。
- 通知栏有暂停/恢复和关闭入口。关闭后从应用重新开启；手机重启后也需要手动开启。

## vivo 后台运行

Y36m 的实际 OriginOS 版本可能已经升级，设置名称可能不同。若面板过一段时间消失：

- 在设置中搜索“后台耗电管理”，找到光点待办并允许后台运行。
- 在最近任务列表中锁定光点待办，以减少被清理的情况。
- 检查悬浮窗、使用情况访问和通知权限仍然开启。
- 省电模式可能限制后台运行，必要时退出省电模式再重新开启悬浮窗。

不需要 root 或无障碍权限。未开启使用情况访问时保留手动收起/展开；无法识别前台应用时默认收起。

## 数据与升级

所有任务存储在手机内，不上传 GitHub。源码仓库公开不代表待办数据公开。完成或删除超过5秒不可恢复；退出进程不会延长撤销截止时间。卸载会删除全部任务，首版无备份功能。

同一应用 ID、同一签名并且版本号不降低时可覆盖升级保留数据。未来版本必须沿用交付安装包的签名，不能用不同 CI 临时 debug 签名覆盖安装。本地签名密钥不放入 GitHub。

交付的“签名备份-请勿上传GitHub.zip”含 `glow-release.jks`、`password.txt` 和操作说明，请留在私人存储中。别名为 `glow`，用于后续正式版本签名。源代码 ZIP 不包含这些文件。
