# vivo Y36m 真机验收

以下必须在实际手机上完成，未打勾代表尚未验证。

- [ ] 记录手机 Android / OriginOS 版本和屏幕字号。
- [ ] 安装 APK，应用正常启动；以同签名后续版本覆盖升级后任务保留。
- [ ] 开启悬浮窗、通知、使用情况访问，回桌面展开，进入微信/浏览器约1秒内收起。
- [ ] 拒绝或撤销各权限时不崩溃；缺少使用情况访问时可手动展开/收起。
- [ ] 0项显示空状态；1项、10项和11项布局正常；11项时仅展示前10项，完成一项补入第11项。
- [ ] 标准字号同时展示10项，大字号、长文本和横屏可滚动，不遮住关键按钮。
- [ ] 左滑只露出按钮，纵向滑动不误触；点击完成播放0.8秒光粒子并平滑补位。
- [ ] 点击完成后4秒内撤销成功，5秒后不可恢复；连续完成多项可分别撤销。
- [ ] 完成后立即停止应用再打开，5秒内仍可撤销，5秒后记录清理。
- [ ] 编辑、上移、下移、删除和重新打开后顺序正确；撤销回到原排序位置。
- [ ] 面板及悬浮球可拖动，位置保存；透明度设置生效。
- [ ] 锁屏任务隐藏，解锁恢复；通知栏暂停、恢复、关闭正确。
- [ ] 亮屏跨应用使用30分钟和待机测试，记录电量与系统是否清理服务。
- [ ] 重启手机后没有自行显示任务，手动打开应用可重新开启面板。
